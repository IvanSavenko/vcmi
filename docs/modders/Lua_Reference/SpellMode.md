# SpellMode

Ways a spell is cast, used by BattleActionEnvironment `castSpell`.

| Key | Value | Description |
| --- | ----- | ----------- |
| `creatureActive` | 2 | Active spell of a unit, cast instead of its attack. |
| `spellLikeAttack` | 4 | Ability of a unit that works like a spell, such as first aid or a catapult shot. |
